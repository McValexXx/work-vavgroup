# Dashboard publishing instructions

For dashboard work in this repository, use the existing VAVGROUP publishing flow. Keep each future dashboard at `dashboards/<unique-slug>/index.html`, so each has its own URL under `work.vavgroup.pro`. Update the root dashboard only when the user requests that dashboard to change.

Build self-contained HTML/CSS/JavaScript with no required external scripts or fonts. Support iPhone screens, touch controls, readable tables, and locally calculated interactive scenarios. Clearly distinguish source facts, calculations, assumptions, and conditional recommendations. Never invent lead yields, sales guarantees, or company reliability ratings.

Check the page, calculations, and small-screen layout before committing. Once GitHub Pages is configured, commits to `main` trigger publication. Verify the deployed URL after publication. Do not claim VPN-free access has been tested unless it was tested on the recipient's network.

Keep credentials, personal data, original private offers, and confidential attachments out of published files. Respect the repository's existing visibility. Do not change visibility, purchase hosting, alter the main VAVGROUP domain, or remove a dashboard without the user's authorization.
